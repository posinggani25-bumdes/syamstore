☁️ Alur Deploy ke GitHub

1

📁 Persiapan File Website

Source code website seperti HTML, CSS, JavaScript, Gambar, Icon, dan Font disusun dalam struktur teratur.

2

📦 Upload ke Repository GitHub

Website diunggah ke repository GitHub agar terorganisir dengan aman.

3

⚙️ Konfigurasi GitHub Pages

Konfigurasi publikasi agar sistem GitHub Pages dapat menampilkan halaman web secara langsung.

4

🌍 Website Siap Diakses

Website mendapatkan alamat URL online yang siap dibagikan ke media sosial dan pelanggan.
